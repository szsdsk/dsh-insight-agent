# 销售示例工作簿

[English](README.md) | 中文

[`insight-sales-demo.xlsx`](insight-sales-demo.xlsx) 是用于 InsightAgent 验收的确定性合成数据集，包含两个首行作为表头的规范工作表：

- `订单`：2026 年 1 月至 6 月的 48 条订单。
- `客户`：8 位客户，`客户ID` 唯一，分属四个地区。

使用 `订单.客户ID = 客户.客户ID` 配置 `INNER JOIN` 或 `LEFT JOIN`。右表键唯一，关联不会重复计算订单销售额。
